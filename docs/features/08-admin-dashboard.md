# Административная панель

## Доступ

Админка работает отдельным Node.js-процессом на `127.0.0.1:8080` и публикуется через Caddy:

```text
https://ticket.crosfit.uz/admin/
```

Все маршруты `/admin/*` защищены HTTP Basic Auth. `/healthz` доступен без авторизации для liveness-проверки.

## Навигация

Desktop использует фиксированный sidebar, mobile — горизонтальную прокручиваемую навигацию. Разделы:

- Обзор;
- Пользователи;
- Цены;
- Переходы;
- Билеты.

Dashboard строится сервером в HTML. Клиентский JavaScript отвечает только за combobox городов и выделение активного раздела.

## Обзор

Первый экран показывает:

- всего пользователей и прирост за 7 дней;
- активные билеты и общее число записей;
- текущую среднюю/минимальную цену;
- человеческие переходы за 30 дней;
- последнюю синхронизацию;
- активные подписки;
- fetched/changed последнего sync;
- график цен за 30 дней;
- график кликов за 30 дней.

## Пользователи

Метрики:

- новые за 7 дней;
- новые за 30 дней;
- с активной подпиской;
- активные аккаунты.

Таблица показывает 12 последних регистраций:

- имя и username/ID;
- статус;
- активные подписки;
- человеческие клики за 30 дней;
- дату регистрации;
- Telegram ID.

## Цены

Текущий диапазон рассчитывается по активным билетам:

- min;
- rounded average;
- max.

График за 30 дней агрегирует все route daily rows по дню:

- самая низкая цена среди маршрутов;
- среднее значение route minimum;
- самый высокий daily maximum;
- суммарное число наблюдений.

Таблица маршрутов показывает до 12 комбинаций origin/destination/class с наибольшим числом наблюдений:

- min/average/max;
- sample count;
- число дней покрытия.

Важно: верхний график — общая рыночная сводка по маршрутам, а не график одного выбранного направления.

## Переходы

Учитывается только `user_agent_kind = human`.

Показываются:

- клики за 24 часа, 7 и 30 дней;
- уникальные пользователи за 30 дней;
- ежедневная серия с нулевыми днями;
- распределение по source;
- 10 самых популярных маршрутов;
- средняя цена билета в момент перехода;
- доля уникальных пользователей от количества кликов.

Preview Telegram и bot/crawler traffic исключаются.

## Каталог билетов

Админка загружает активные билеты и поддерживает:

- локальные/международные;
- туда-обратно/в одну сторону;
- точную дату вылета;
- точную дату возврата;
- поиск по русскому названию или IATA;
- сортировку по городу, цене или дате;
- asc/desc;
- pagination по 50 строк.

Таблица выводит маршрут, тип, цену, даты, класс, прямой рейс, багаж и ссылку.

## Ручная синхронизация

Кнопка `Запустить sync` выполняет тот же `SyncHotTicketsJob`, что cron и CD. Запрос ждёт завершения job, затем возвращает dashboard с flash-сообщением и количеством обработанных источников.

Одновременный запуск защищён application lock и системным `flock` для cron. Если другой sync уже держит application lock, источник получает статус `skipped`.

## Актуальность данных

Админка не использует отдельный dashboard cache. Каждый GET `/admin/` повторно читает SQLite. Новые результаты становятся видимыми после завершения sync и обновления страницы.
