# Telegram Mini App

## Назначение

Mini App — основной визуальный интерфейс продукта. Он использует существующего Telegram-пользователя и общую SQLite-базу, поэтому изменения профиля и Watchlist сразу видны в боте.

Production URL:

```text
https://ticket.crosfit.uz/app/
```

## Основная навигация

Нижнее меню содержит три раздела:

- `Deals`;
- `Watchlist`;
- `Профиль`.

Карточка билета и форма нового отслеживания открываются как отдельные экраны без нижней навигации.

## Deals

Экран показывает активные предложения из Ташкента с учётом пользовательского класса и багажа.

Карточка содержит:

- IATA-маршрут и названия городов;
- цену;
- даты;
- прямой рейс/пересадку;
- багаж;
- пояснение на основе истории цены;
- badge выгодности, если накоплено достаточно данных.

Фильтры интерфейса:

- destination;
- максимальная цена;
- только прямые;
- только с багажом;
- выгодные, дешёвые, недавние или скоро вылет.

Кнопка обновления повторно загружает каталог. Состояния загрузки, пустого результата и ошибки имеют отдельный UI.

## Детальная карточка

После выбора предложения Mini App загружает билет и 30-дневную историю маршрута.

Экран содержит:

- цену и Deal Score;
- время последнего обновления;
- дату вылета и возврата;
- тип рейса;
- багаж;
- авиакомпанию;
- класс;
- историю минимальной цены;
- минимум, медиану и максимум;
- переключатель 7/30/90 дней;
- кнопку открытия билета;
- кнопку отслеживания направления.

График показывается после накопления минимум семи дневных точек. До этого отображается объясняющее пустое состояние.

## Watchlist

Показывает все подписки пользователя, включая отключённые. Для каждой карточки выводятся:

- маршрут или `ANY`;
- диапазон дат;
- максимальная цена;
- прямой рейс;
- багаж;
- активность.

В заголовке показывается число активных подписок из лимита 20. Наличие активной подписки обозначается точкой у вкладки Watchlist.

## Профиль

Профиль показывает Telegram-имя, фиксированные origin/currency и позволяет изменить:

- `Эконом` / `Бизнес`;
- `Не важно` / `Только с багажом`.

После сохранения настройки начинают применяться и в Mini App, и в боте.

## Интеграция с Telegram WebApp

При запуске Mini App:

- применяет тёмные цвета header/background/bottom bar Telegram;
- вызывает `ready()`;
- вызывает `expand()`;
- использует haptic feedback для ключевых действий;
- передаёт `Telegram.WebApp.initData` в каждом API-запросе.

Если production-страница открыта вне Telegram и `initData` отсутствует, приложение блокирует интерфейс и просит открыть Hot Ticket из Telegram.

## Demo mode

При открытии через `file:`, `localhost` или `127.0.0.1` frontend использует встроенные demo-данные. Этот режим предназначен только для локальной разработки дизайна и не обращается к production API.

## Frontend-технология

Mini App написан без frontend-framework:

- статический `index.html`;
- CSS;
- JavaScript modules;
- Canvas для пользовательского графика цены;
- Telegram WebApp JS SDK.
